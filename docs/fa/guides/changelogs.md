# تاریخچه تغییرات

در [این بخش](https://panel.virakcloud.com/changelogs) فهرست همه‌ی به‌روزرسانی‌های پنل ویراک را می‌بینید: چه چیزی اضافه، اصلاح، تغییر یا حذف شده و از کدام نسخه. برای ورود، از منوی کناری روی **گزارش تغییرات** کلیک کنید.

## خواندن هر نسخه

جدیدترین نسخه بالای صفحه است. هر کارت شماره‌ی نسخه و تاریخ انتشار آن را نشان می‌دهد (در نسخه‌ی فارسی به تاریخ شمسی) و تغییرات همان نسخه در دسته‌های زیر آمده است:

| دسته               | معنی                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| ویژگی، اضافه شده   | چیز جدیدی به پنل اضافه شده است                                                |
| بهبود یافته        | قابلیتی که از قبل بود، بهتر یا روان‌تر شده است                                |
| تغییر یافته        | رفتار یا ظاهر چیزی عوض شده است. اگر چیزی با قبل فرق دارد، اول اینجا را ببینید |
| رفع شده            | یک مشکل برطرف شده است                                                         |
| حذف شده، منسوخ شده | چیزی برداشته شده یا به‌زودی برداشته می‌شود                                    |
| امنیت              | مورد مربوط به امنیت                                                           |

## شماره‌ی نسخه یعنی چه؟

شماره‌ی نسخه سه عدد دارد، مثل `3.14.0`:

- **عدد آخر** (`3.13.5`): رفع مشکل‌های کوچک.
- **عدد وسط** (`3.14.0`): قابلیت یا بهبود تازه.
- **عدد اول** (`3.0.0`): تغییر بزرگ و گسترده. این حالت نادر است.

## وقتی نسخه‌ی جدید منتشر می‌شود

لازم نیست صفحه را مرتب چک کنید؛ خود پنل خبر می‌دهد. شکل اطلاع‌رسانی به نوع نسخه بستگی دارد:

| نوع نسخه                                       | چه می‌بینید                                                          |
| ---------------------------------------------- | -------------------------------------------------------------------- |
| **اصلاحی** (مثلاً `3.13.4` به `3.13.5`)        | یک نوار کوچک پایین صفحه با دکمه‌های **بروزرسانی کن** و **نه، ممنون** |
| **میانی یا اصلی** (مثلاً `3.13.5` به `3.14.0`) | یک پنجره‌ی اطلاع‌رسانی                                               |

- با **بروزرسانی کن**، صفحه با نسخه‌ی جدید دوباره بارگذاری می‌شود. اگر در حال پر کردن یک فرم هستید (مثلاً ساخت سرور)، اول کار خود را ثبت کنید.
- نوار اطلاع‌رسانی تا وقتی انتخاب نکنید می‌ماند و خودبه‌خود بسته نمی‌شود.
- با **نه، ممنون**، برای همین نسخه دیگر در همین مرورگر پیام نمی‌بینید.

## این صفحه کی به کار می‌آید؟

- بعد از یک به‌روزرسانی، تا ببینید دقیقاً چه عوض شده است.
- وقتی چیزی در پنل با مستندات فرق دارد.
- وقتی می‌خواهید مطمئن شوید مشکلی که دیده بودید رفع شده است.

::: tip نکته
اگر تغییری را در پنل می‌بینید که در این صفحه ثبت نشده، آن را به [پشتیبانی](/fa/guides/tickets/create) گزارش دهید.
:::
