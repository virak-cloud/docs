# لیست دیتابیس‌ها

## معرفی ​

این صفحه تمام دیتابیس‌های ساخته‌شده داخل یک پروژه را نمایش می‌دهد. برای رسیدن به این صفحه، از [لیست پروژه‌ها](./namespace-list.md) یک پروژه را باز کنید.

## ستون‌های جدول ​

برای هر دیتابیس، اطلاعات زیر نمایش داده می‌شود:

- **شماره**: شماره ردیف.
- **نام**: نامی که برای دیتابیس انتخاب کرده‌اید.
- **دیتابیس انجین**: آیکون موتور به همراه نام و نسخه موتور دیتابیس (مثلاً PostgreSQL نسخه ۱۷.۹ یا MySQL نسخه ۸.۴.۷-۷.۱).
- **تاریخ ساخت**: تاریخ ایجاد دیتابیس.
- **وضعیت**: وضعیت فعلی دیتابیس.

## عملیات‌ها ​

برای هر دیتابیس، عملیات‌های زیر در دسترس است:

- **مشاهده جزئیات**: ورود به [صفحه جزئیات دیتابیس](./details.md)، جایی که می‌توانید اطلاعات اتصال را ببینید، منابع را ارتقا دهید، بکاپ‌گیری را مدیریت کنید و مصرف منابع را مانیتور کنید.
- **حذف**: حذف کامل دیتابیس.

## ساخت دیتابیس ​

برای [ساخت دیتابیس](./create.md) جدید داخل پروژه فعلی، روی دکمه **ایجاد دیتابیس** در بالای صفحه کلیک کنید. با این کار وارد [صفحه ساخت دیتابیس](./create.md) می‌شوید، جایی که موتور، نسخه و بسته منابع را انتخاب می‌کنید.
