# اطلاعات شبکه

در صفحه جزئیات شبکه، تب **اطلاعات شبکه** به شما امکان می‌دهد مشخصات آدرس‌دهی داخلی و آدرس‌های IP عمومی روتر مجازی خود را مشاهده و مدیریت کنید.

::: warning توجه
این بخش فقط برای **روتر مجازی (لایه ۲ + ۳)** نمایش داده می‌شود. در شبکه‌های **سوئیچ مجازی (لایه ۲)** به دلیل نداشتن روتر، صفحه جزئیات فقط یک تب به نام **سرورهای ابری متصل** دارد.
:::

## اطلاعات پیکربندی

در این کارت، آدرس درگاه و سابنت شبکه داخلی خود را مشاهده می‌کنید. با کلیک روی آیکن کنار هر آدرس، می‌توانید آن را کپی کنید:

- **IPv4:**
  - **درگاه (Gateway):** آدرس IP خصوصی روتر مجازی که موقع ساخت شبکه مشخص کرده‌اید (مثلاً `192.168.1.1`).
  - **سابنت مسک (Subnet Mask):** ماسک شبکه داخلی که همواره برابر با `255.255.255.0` (سابنت ۲۴/) است.
- **IPv6:**
  اگر پلن شبکه شما از هر دو نسخه IP پشتیبانی کند (`IPv4 + IPv6`)، آدرس درگاه و سابنت IPv6 که به‌صورت خودکار توسط سیستم تخصیص داده شده است در این تب نمایش داده می‌شود. در شبکه‌هایی که فقط IPv4 هستند، این تب غیرفعال است.

## IPهای عمومی

روتر مجازی برای اتصال سرورها به اینترنت و دسترسی از خارج به داخل، از IPهای عمومی استفاده می‌کند.

### ستون‌های جدول

- **شماره:** ردیف IP.
- **آدرس IP:** آدرس عمومی به همراه دکمه کپی.
- **تاریخ ایجاد:** زمان اضافه شدن IP به شبکه.
- **SourceNAT:** نشان می‌دهد کدام IP به عنوان آدرس خروجی اصلی شبکه کار می‌کند.
- **عملیات:** دکمه‌های مربوط به استاتیک NAT و جداسازی IP.

### IP عمومی پیش‌فرض (SourceNAT)

به محض اتصال اولین سرور ابری به روتر مجازی، به‌صورت خودکار یک IP عمومی به عنوان **SourceNAT** به شبکه شما داده می‌شود:

- تمام سرورهای متصل به این شبکه برای اتصال به اینترنت، خروجی ترافیک خود را از این آدرس ارسال می‌کنند.
- این IP عمومی پیش‌فرض **غیرقابل جداسازی و غیرقابل حذف** است و فقط با حذف کل شبکه آزاد می‌شود.
- روی این IP نمی‌توان قابلیت استاتیک NAT را فعال کرد؛ اما برای انتقال پورت (Port Forwarding)، توزیع بار (Load Balancing) و فایروال قابل استفاده است.

### افزودن IP عمومی جدید (اتصال IP)

اگر برای سرویس‌های خود به IP عمومی بیشتری نیاز دارید، روی دکمه **اتصال IP** در بالای جدول کلیک کنید تا یک IP عمومی جدید به روتر شما متصل شود. از این IP می‌توانید برای استاتیک NAT، انتقال پورت یا توزیع بار استفاده کنید.

### جداسازی IP

برای حذف IPهای عمومی اضافه‌ای که دیگر به آن‌ها نیاز ندارید، روی آیکن ضربدر قرمز (جداسازی IP) در ردیف همان IP کلیک کنید تا از شبکه شما جدا شود.

::: tip نکته
دکمه جداسازی برای IP پیش‌فرض (SourceNAT) همیشه غیرفعال است.
:::

## استاتیک NAT (Static NAT)

قابلیت استاتیک NAT به شما امکان می‌دهد تمام ترافیک ورودی یک IP عمومی را مستقیماً به یکی از سرورهای متصل به شبکه وصل کنید (ارتباط یک‌به‌یک). در این حالت نیازی به تعریف تک‌تک پورت‌ها نیست و هر درخواستی که به این IP عمومی ارسال شود، مستقیماً به آن سرور هدایت می‌شود.

### فعال‌سازی استاتیک NAT

1. در جدول IPهای عمومی، روی دکمه **افزودن استاتیک NAT** در ردیف IP مورد نظرتان کلیک کنید.
2. از فهرست بازشده، سرور ابری مورد نظر را انتخاب کنید (اگر سرور شما چند IP دارد، می‌توانید IP دقیق مقصد را انتخاب کنید).
3. دکمه تایید را بزنید تا ارتباط برقرار شود.

### مشاهده و حذف استاتیک NAT

وقتی استاتیک NAT برای یک IP فعال باشد، یک فلش در ردیف آن در جدول ظاهر می‌شود. با کلیک روی آن، اطلاعات زیر نمایش داده می‌شود:

- نام سرور ابری متصل
- IP داخلی سرور
- تاریخ اتصال
- دکمه **حذف استاتیک NAT** (آیکن سطل زباله) برای لغو اتصال

::: warning نکته مهم درباره استاتیک NAT
وقتی یک IP عمومی را به استاتیک NAT اختصاص می‌دهید، تمام ترافیک آن فقط به همان سرور می‌رود؛ بنابراین:

- این IP دیگر در بخش‌های **انتقال پورت (Port Forwarding)** و **توزیع بار (Load Balancing)** قابل انتخاب نیست.
- برای مدیریت دسترسی‌ها به این IP، فقط می‌توانید از قوانین **فایروال (Firewall)** استفاده کنید.
  :::
