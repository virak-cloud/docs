# Authentication

After logging into your panel, you need to complete the authentication process. This process consists of a few steps that differ slightly depending on your account type (personal or company).

## Selecting Account Type ​

In the first step, choose your account type:

- **Person**: For individuals, suited to personal use.
- **Company**: For companies and legal entities.

<DarkModeImage
  dark-src="/images/guides/en/dark/user/auth-account-type.webp"
  light-src="/images/guides/en/light/user/auth-account-type.webp"

/>

::: tip Note
You can change your account type later as well; from your profile section, you can switch between Person and Company account types.
:::

Once you select an account type, the following steps will differ based on your choice.

## Person Account Path ​

### Identity Information ​

In this step, enter your identity information:

- Name
- Family name
- Father's name
- Certificate number
- National code
- Place of birth
- Birth date
- Gender

<DarkModeImage
  dark-src="/images/guides/en/dark/user/auth-identity-info.webp"
  light-src="/images/guides/en/light/user/auth-identity-info.webp"
  alt="Identity Information"
/>

### Residence Information ​

In the next step, enter your residence information:

- Country
- Province
- City
- Province code
- Telephone
- Zip code
- Address

<DarkModeImage
  dark-src="/images/guides/en/dark/user/auth-residence-info.webp"
  light-src="/images/guides/en/light/user/auth-residence-info.webp"
  alt="Residence Information"
/>

## Company Account Path ​

### Company Information ​

If you selected the Company account type, this step asks for your company's information:

- Company name
- Registration code
- Economic ID (tax code)
- Company registration date
- Company mobile number

### Company Representative Information ​

Next, you provide the identity information of the company's representative; these fields are the same as the Identity Information step in the Person account path:

- Name
- Family name
- Father's name
- Certificate number
- National code
- Place of birth
- Birth date
- Gender

### Residence Information ​

Following that, just like the Person account path, you need to provide residence information (country, province, city, province code, telephone, zip code, and address).

## Mobile Number Verification ​

For both paths (Person and Company), the final step is the same:

1. Enter your mobile number and click **Send Code**.

<DarkModeImage
  dark-src="/images/guides/en/dark/user/auth-mobile-number.webp"
  light-src="/images/guides/en/light/user/auth-mobile-number.webp"
  alt="Enter Mobile Number"
/>

2. Enter the 6-digit code sent to your mobile number.

<DarkModeImage
  dark-src="/images/guides/en/dark/user/auth-otp.webp"
  light-src="/images/guides/en/light/user/auth-otp.webp"
  alt="Enter Verification Code"
/>

Once the code is confirmed, your authentication process is complete.

::: warning Note
If the information you submitted (name, family name, father's name, birth date, or gender) does not match the reference used for verification, a message similar to the one below is shown, and you will need to review and correct your information:

> The information submitted does not match the matching reference in one or more of the following fields:
> First name, last name, fathers name, date of birth, gender
> :::
