# Dashboard

## Main Page Information

After logging into the [panel](https://panel.virakcloud.com/), you can view the following widgets on the dashboard's main page:

1. **Recent Instances**: A table of your most recent cloud instances, including name, operating system, server location, status, and quick access to each instance's details. Click **Show More** to go to the full list of cloud instances.
2. **Hardware Resources**: A chart-based view of your panel's resource usage and limits (RAM, CPU, disk), as well as the number of cloud instances used versus your panel's instance limit.
3. **Latest Content**: Links to the latest articles and tutorials from the Virak Cloud blog.
4. **Latest Events**: A table of the latest security and account-related events (such as logins from an unusual IP address), along with the date and time of each event. Click **Show More** to access the full event log report.
5. **Support**: Shows your most recent support tickets (last 3 tickets).
