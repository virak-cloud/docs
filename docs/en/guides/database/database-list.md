# List of Databases

## Introduction ​

This page shows all the databases created inside a namespace. To reach this page, open a namespace from the [List of Namespaces](./namespace-list.md) page.

<DarkModeImage
  dark-src="/images/guides/en/dark/database/database-list.png"
  light-src="/images/guides/en/light/database/database-list.png"
  alt="List of Databases"
/>

## Table Columns ​

For each database, the following information is displayed:

- **Number**: The row number.
- **Name**: The name you chose for the database.
- **Database Engine**: The engine icon along with the engine name and version (e.g., PostgreSQL v17.9, MySQL v8.4.7-7.1).
- **Created Date**: The date the database was created.
- **Status**: The current status of the database.

## Actions ​

Each database has the following actions available:

- **View Details**: Opens the [database details page](./details.md), where you can see connection information, upgrade resources, manage backups, and monitor resource usage.
- **Delete**: Permanently deletes the database.

## Creating a Database ​

To [create a new database](./create.md) inside the current namespace, click the **Create Database** button at the top of the page. This opens the [database creation page](./create.md), where you choose the engine, version, and resource package.
